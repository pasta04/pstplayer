# 機能仕様

PSTPlayer が提供すべき機能の一覧。PCRPlayer の機能を網羅した上で、クロスプラットフォーム化に伴う取捨選択を明示する。

優先度凡例: **★★★** = MVP 必須 / **★★** = v1.0 までに / **★** = v1.0 以降 / **—** = 採用しない

---

## 1. 再生 (Player)

| 機能                            | 優先度  | 備考                                                              |
| ------------------------------- | ------- | ----------------------------------------------------------------- |
| PeerCast チャンネル URL 再生    | ★★★ | `http://host:port/pls/{id}` を貼り付けて再生                      |
| クリップボードからの URL 自動検出 | ★★★ | Ctrl/Cmd+V で URL を解釈                                          |
| 再生/一時停止/停止              | ★★    | ライブ視聴用途のため緊急時のみ。右クリックメニューとホットキーから |
| 音量調整・ミュート              | ★★★ |                                                                   |
| 全画面表示                      | ★★★ |                                                                   |
| アスペクト比切り替え            | ★★    | 自動 / 16:9 / 4:3 / 16:10 / 自由比率                              |
| 画面サイズプリセット            | ★★    | 50%/75%/100%/125%/150%/200% など                                  |
| 常に最前面                      | ★★    |                                                                   |
| ボーダーレス / タイトルバー非表示 | ★★    |                                                                   |
| スナップショット (静止画保存)   | ★      | PNG/JPEG                                                          |
| 録画                            | ★      | mpv の `stream-record` で実現可能                                 |
| 倍率細かな調整 (10 段階)        | ★      | PCRPlayer の Ctrl+1〜9 相当                                       |
| シーク                          | —       | ライブストリームのため意味薄。VOD 機能を入れた段階で要検討         |

## 2. PeerCast 連携

| 機能                                | 優先度  | 備考                                                            |
| ----------------------------------- | ------- | --------------------------------------------------------------- |
| チャンネル情報の表示                | ★★★ | 名前、ジャンル、詳細、ビットレート、リスナー/リレー数、コメント |
| Track 情報 (現在演奏中の曲名等) 表示 | ★★    |                                                                 |
| Bump (再接続)                       | ★★★ |                                                                 |
| 切断 (Stop)                         | ★★★ |                                                                 |
| 配信時間 (uptime) 表示              | ★★    |                                                                 |
| リレー状況の取得                    | ★★    | リレー数 0 のときの警告など                                     |
| YP からのチャンネル一覧             | ★★    | index.txt を取得して一覧表示                                    |

## 3. 掲示板 (BBS)

### 3.1 共通

| 機能                          | 優先度  | 備考                                                             |
| ----------------------------- | ------- | ---------------------------------------------------------------- |
| コンタクト URL からの自動判定 | ★★★ | URL パターンで掲示板タイプを識別                                 |
| スレッド一覧表示              | ★★★ |                                                                  |
| スレッド本文取得・表示        | ★★★ |                                                                  |
| 自動更新 (差分取得)           | ★★★ | If-Modified-Since + Range で効率取得                             |
| 書き込み (POST)               | ★★★ | 名前/メール/本文                                                 |
| 投稿エラー (規制等) の表示    | ★★★ |                                                                  |
| アンカー (>>N) パース・ジャンプ | ★★★ |                                                                  |
| ID 抽出 (ID:xxx)              | ★★★ |                                                                  |
| 同一 ID のレス抽出表示        | ★★    |                                                                  |
| URL の自動リンク化            | ★★    | http(s)://、画像/動画は別ペインプレビュー (v1.0 以降)             |
| レス番号での抽出              | ★★    |                                                                  |
| キーワード検索                | ★★    |                                                                  |
| 新着レス通知                  | ★★    | OS 標準通知 (Tauri Notification API)                             |
| スレッドが落ちた時の検知      | ★★    |                                                                  |

## 6. ウィンドウ / 表示要素

「表示」メニュー (右クリック → 表示) から各要素を個別に ON/OFF できる。

| 表示要素                              | 優先度  | デフォルト | 備考                                                  |
| ------------------------------------- | ------- | ---------- | ----------------------------------------------------- |
| タイトルバー                          | ★★    | ON         | キー `X` でトグル                                     |
| ウィンドウ枠 (ボーダー)               | ★★    | ON         | キー `Z` でトグル                                     |
| BBS ペイン                            | ★★★ | ON         | キー `C` でトグル                                     |
| スレッドタイトル帯                    | ★★    | ON         | 個別 ON/OFF 可、BBS ペイン非表示時は連動して非表示    |
| 書き込み欄                            | ★★    | ON         |                                                       |
| ステータス帯                          | ★★    | ON         | キー `B` でトグル                                     |
| オーバーレイ: チャンネル名            | ★★    | ON         | 動画上に半透明の角丸ラベル                            |
| オーバーレイ: 配信時間                | ★★    | ON         |                                                       |
| オーバーレイ: 現在 FPS                | ★      | OFF        |                                                       |
| オーバーレイ: 現在時刻                | ★      | OFF        |                                                       |
| オーバーレイ: ビットレート            | ★      | OFF        |                                                       |
| サブペインの位置切替 (左/右/上/下)    | ★★    | 右         | 設定ダイアログから変更                                |

すべての表示状態は設定に永続化され、起動時に復元される。
| 終了時のウィンドウ位置・サイズ記憶    | ★★★ |                                               |
| マルチディスプレイ対応                | ★★    |                                               |

## 7. 採用しないもの (— 印)

| 機能                        | 理由                                                                          |
| --------------------------- | ----------------------------------------------------------------------------- |
| IE 埋め込みブラウザ         | 廃止技術。Tauri WebView に置き換え                                            |
| DirectShow カスタムプレゼンタ | Windows 専用。libmpv で代替                                                   |
| 専用 FLV スプリッタ         | libmpv (FFmpeg) が標準対応                                                    |
| Windows レジストリ依存設定  | クロスプラットフォーム不可。ファイルベースに統一                              |
| MFC リソース系のローカライズ | 全て JSON/TOML ベースに統一                                                   |

## 機能の優先順位サマリ

**MVP (v0.1)**: 1 (再生基本) + 2 (PeerCast 連携基本) + 3.1 (BBS 基本) + 3.2 (したらば) + 5 (設定永続化基本)

**v0.5**: 上記 + サブペイン + 2ch 系 + 通知 + テーマ + ショートカット

**v1.0**: 機能網羅 + 安定性 + 3 OS のリリースバイナリ提供
