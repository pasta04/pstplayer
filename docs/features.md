# 機能仕様

PSTPlayer が提供すべき機能の一覧。

**スコープ方針** ([ADR-0004](decisions/0004-scope.md)):

- PCRPlayer のオンライン視聴機能 (PeerCast 配信 + 連動掲示板) と等価
- ライセンスは MIT、実装はクリーンルーム ([ADR-0002](decisions/0002-license-clean-room.md))
- オフライン系 (ローカル動画再生 / シークバー / フィルタグラフ等) はオミット

優先度凡例: **★★★** = MVP 必須 / **★★** = v1.0 までに / **★** = v1.0 以降 / **—** = 採用しない

### 2.1 CLI 引数経由の起動 (外部連携)

PCRPlayer 同様、YP ブラウザ / PeerCastStation の Web UI / 録画ツール等の外部ソフトから、コマンドライン引数として配信 URL とチャンネル情報を渡されて起動するシナリオに対応する。

#### 引数フォーマット

```
pstplayer <URL> [チャンネル名] [長オプション...]
```

PCRPlayer の起動側設定 (例: `"$X" "$0"`) をそのまま流用できるよう、**位置引数として URL とチャンネル名を受け取る**。

| 位置 | 内容           | 必須 | 用途                                                  |
| ---- | -------------- | ---- | ----------------------------------------------------- |
| 1    | 配信 URL       | 必須 | プレイリスト URL or ストリーム URL                    |
| 2    | チャンネル名   | 任意 | タイトルバー初期表示用 (`getChannelInfo` 取得前)      |

#### 起動コマンド例

```
# 最小 (URL のみ)
pstplayer "http://localhost:7144/pls/0123456789ABCDEF0123456789ABCDEF?tip=192.0.2.1:7144"

# PCRPlayer 互換 (URL + チャンネル名)
pstplayer "http://localhost:7144/pls/0123456789ABCDEF0123456789ABCDEF?tip=192.0.2.1:7144" "テスト配信"
```

#### 受け取る URL のバリエーション (PCRPlayer 互換)

| 形式                                            | 説明                                              |
| ----------------------------------------------- | ------------------------------------------------- |
| `http://Host:Port/pls/{id}[?tip={tip}]`         | プレイリスト URL (ホスト名形式)                  |
| `http://Host:Port/pls/{id}.{ext}[?tip={tip}]`   | 拡張子付きプレイリスト                            |
| `http://Host:Port/stream/{id}.{ext}`            | ストリーム直 URL                                  |
| `http://IP:Port/pls/{id}[?tip={tip}]`           | IP 形式 (ホスト名解決をスキップ)                  |
| `http://IP:Port/stream/{id}.{ext}`              | IP 形式ストリーム                                 |

- `?tip={ip:port}` パラメータ: トラッカー IP (任意)。指定があれば PeerCast 本体に渡してリレー接続を促進

#### 起動時の動作フロー

1. CLI 引数をパース (第 1 引数 URL、第 2 引数チャンネル名、長オプション)
2. URL を解析して `{host, port, channel_id}` を抽出
3. 第 2 引数があれば即座にタイトルバーに表示 (体感速度向上)
4. PeerCast 本体 (`http://host:port/api/1`) に `getChannelInfo(id)` で問い合わせ
5. チャンネル名 / コンタクト URL / ビットレート等を取得 (引数で渡されなかった項目を補完)
6. コンタクト URL がある場合は BBS ペインを自動初期化 (したらば等を判定)
7. プレイリスト URL の場合は中身をパースして実ストリーム URL を取得
8. libmpv に渡して再生開始

#### 多重起動の挙動 (設定で選択)

| 設定値                     | 挙動                                                            |
| -------------------------- | --------------------------------------------------------------- |
| `new-window` (デフォルト)  | 新規ウィンドウで起動 (同時に複数チャンネル視聴可)               |
| `replace`                  | 既存ウィンドウの再生チャンネルを差し替え                        |
| `single`                   | 既存ウィンドウをフォーカスして引数を無視                        |

#### 長オプション (拡張: PCRPlayer の他の `$` 変数に対応)

PCRPlayer の起動側が展開できる変数 (`$0` 〜 `$L`) のうち、PSTPlayer が UI で意味的に使えるものは長オプションで受け取れるようにする。これにより、起動側設定で `"$X" "$0" --contact="$3" --genre="$4"` のような形で追加情報を渡せる。

| オプション           | PCRPlayer 変数 | 内容                                            |
| -------------------- | -------------- | ----------------------------------------------- |
| `--name=<str>`       | `$0`           | チャンネル名 (位置引数 2 と同等、明示用)        |
| `--id=<hex32>`       | `$1`           | チャンネル ID (URL からも抽出可、検証用)        |
| `--tip=<ip:port>`    | `$2`           | トラッカー IP (URL クエリと同等)                |
| `--contact=<url>`    | `$3`           | コンタクト URL (BBS ペイン即時初期化用)         |
| `--genre=<str>`      | `$4`           | ジャンル                                        |
| `--desc=<str>`       | `$5`           | 詳細                                            |
| `--bitrate=<int>`    | `$8`           | ビットレート kbps                               |
| `--type=<str>`       | `$9`           | コンテナタイプ                                  |
| `--comment=<str>`    | `$H`           | コメント                                        |
| `--yp-name=<str>`    | `$J`           | YP 名                                           |
| `--yp-url=<url>`     | `$K`           | YP の URL                                       |

これらは **すべて任意**。指定されたものは `getChannelInfo` の結果より優先 (ユーザが渡した情報を尊重)。指定されなかった項目は PeerCast から取得して補完する。

#### 制御系オプション

| オプション           | 内容                                                            |
| -------------------- | --------------------------------------------------------------- |
| `--no-autoplay`      | 起動だけして再生は手動 (ウィンドウは表示)                       |
| `--no-bbs`           | コンタクト URL があっても BBS ペインを初期化しない              |
| `--minimized`        | 最小化状態で起動                                                |
| `--help` / `-h`      | 使い方を表示して終了                                            |
| `--version` / `-V`   | バージョン表示して終了                                          |

#### シェル / クォートの注意

URL には `?` `&` `=` `:` などのシェルメタ文字が含まれるため、**起動側ツールは必ず引数をクォートで囲む**。これは起動側 (PCRPlayer 互換ツール / バッチファイル / スクリプト) の責務であり、PSTPlayer 受け取り側では特別な処理は不要 (Rust の `std::env::args()` が OS の引数配列を正しく返してくれる)。

OS シェル別の渡し方:

| シェル               | 例                                                                 | 補足                                |
| -------------------- | ------------------------------------------------------------------ | ----------------------------------- |
| Windows cmd.exe      | `pstplayer.exe "http://h:p/pls/ID?tip=t" "name"`                  | `"…"` 内なら `&` `<` `>` も安全     |
| Windows PowerShell   | `& pstplayer.exe "http://h:p/pls/ID?tip=t" "name"`                | `&` (呼び出し演算子) と URL の `&` を区別。クォート必須 |
| bash / zsh           | `pstplayer 'http://h:p/pls/ID?tip=t' 'name'`                      | シングルクォート推奨。展開を抑制    |
| sh (POSIX 互換)      | `pstplayer "http://h:p/pls/ID?tip=t" "name"`                      |                                     |

PCRPlayer の起動側設定の典型は `"$X" "$0"` のように既にクォート済み。**PCRPlayer の設定をそのまま PSTPlayer に向ければ動作する**。

#### カスタム URL スキーマ (将来検討)

将来 `pstplayer://` スキーマを OS に登録すれば、ブラウザのリンクから直接起動できる:

```
pstplayer://launch?url=http%3A%2F%2Fh%3Ap%2Fpls%2FID%3Ftip%3Dt&name=name
```

- URL 全体をパーセントエンコード → シェルクォート問題が完全に消える
- Tauri の `bundle.windows.fileAssociations` / `bundle.macOS.associations` で登録可
- v1.0 以降の検討事項として [roadmap.md](roadmap.md) のフェーズ 4 に追加予定

## 6. ウィンドウ / 表示要素

「表示」メニュー (右クリック → 表示) から各バー類とその構成要素を個別に ON/OFF できる (PCRPlayer 互換)。**動画の上に半透明で重なる UI (mpv OSC のような) は設けない**。

### バー類の表示 ON/OFF

| 表示要素                            | 優先度  | デフォルト | 備考                                            |
| ----------------------------------- | ------- | ---------- | ----------------------------------------------- |
| 最前面表示                          | ★★    | OFF        | キー `T` でトグル                               |
| フレーム (ウィンドウ枠)             | ★★    | ON         | キー `Z` でトグル                               |
| タイトルバー                        | ★★    | ON         | キー `X` でトグル                               |
| ステータスバー                      | ★★    | ON         | キー `B` でトグル                               |
| BBS ペイン                          | ★★★ | ON         | キー `C` でトグル                               |
| BBS ペイン位置                      | ★★    | 右         | 上/下/左/右 を選択                              |
| BBS ペインの書き込み欄表示          | ★★    | ON         | BBS ペイン非表示時は自動で無効化                |

### バー内の表示要素

| 表示要素                                  | 優先度 | デフォルト | 備考                                |
| ----------------------------------------- | ------ | ---------- | ----------------------------------- |
| タイトルバーに画面サイズ表示              | ★★    | ON         | 例: `1280×720`                      |
| タイトルバーにソースサイズ表示            | ★      | OFF        | 例: `[src 1920×1080]`               |
| ステータスバーに FPS 表示                 | ★★    | ON         | 例: `(59.99/60.00)`                 |

| ステータスバーで再生情報を優先表示        | ★★    | ON         | チャンネル名/bps を優先             |

## 7. 採用しないもの (— 印)

スコープ方針 ([ADR-0004](decisions/0004-scope.md)) と技術スタック決定に基づき、以下は実装しない。

### スコープ外 (オフライン / 用途不一致)

| 機能                                          | 理由                                                                          |
| --------------------------------------------- | ----------------------------------------------------------------------------- |
| ローカルファイル / URL 直接再生               | スコープ外。mpv/VLC を使えばよい                                              |
| オフライン再生メニュー                        | 同上                                                                          |
| シークバー                                    | PeerCast はライブなのでシーク不可                                              |
| シークバーにファイル名表示                    | シークバー自体が不要                                                          |
| ステータスバーで時間を可変表示 (オフライン)   | オフライン用の現在/総時間表示。オンライン配信時間で代替                      |

### 技術置換 (PCRPlayer の Windows 固有実装の代替)

| PCRPlayer の機能              | PSTPlayer での代替                                                            |
| ----------------------------- | ----------------------------------------------------------------------------- |
| DirectShow カスタムプレゼンタ | libmpv で代替                                                                 |
| 専用 FLV スプリッタ           | libmpv (FFmpeg) が標準対応                                                    |
| IE 埋め込み内蔵 BBS ブラウザ  | Tauri WebView の BBS ペイン (プレーン / HTML レンダリング両方サポート)        |
| フィルタグラフメニュー        | DirectShow 固有のため不要                                                     |
| 実行優先度メニュー            | クロスプラットフォームでは OS 依存が大きいためオミット                        |
| Windows レジストリ設定        | ファイルベース (`config.toml`) に統一                                         |
| MFC リソース系のローカライズ  | JSON/TOML ベースに統一                                                        |
