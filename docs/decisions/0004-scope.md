# ADR-0004: 機能スコープ — PCRPlayer 互換 + オフライン系オミット

- **ステータス**: 採用 (2026-05-30)
- **決定者**: pasta04 (リポジトリオーナー)

## 背景

PSTPlayer の機能スコープを明確にする必要がある。PCRPlayer は元々 Windows ローカル動画再生ソフトとしての側面 (オフライン再生、シークバー、ファイル/URL 直接再生など) も持つが、PSTPlayer の本来のユースケースは **PeerCast のライブ配信視聴 + 連動掲示板** に絞られる。

## 決定

1. **PSTPlayer は PCRPlayer と機能等価を目指す**
   - ユーザーが PCRPlayer から乗り換えても違和感のない操作感
   - 右クリックメニューの構成・キーボードショートカット・表示要素の ON/OFF を PCRPlayer 互換に揃える
2. **実装はクリーンルーム** (ADR-0002 参照)
   - PCRPlayer のソースコードは参照しない
   - 機能リスト / 公開された UI / 公開プロトコル仕様のみを根拠とする
3. **オフライン系の機能はオミット**
   - 「PeerCast 配信視聴 + BBS」というオンライン用途に集中
   - オフライン関連は実装しない (将来的に必要になれば再検討)

## 対象とする機能 (採用)

PCRPlayer のオンライン視聴で意味を持つ機能群:

- PeerCast チャンネル URL からの視聴
- チャンネル情報表示 / Bump (再接続) / Stop (切断)
- BBS ペイン (スレ一覧、レス表示、書き込み)
- 表示要素 (タイトルバー / ステータスバー / BBS ペイン / 各種子要素) の ON/OFF
- ウィンドウ操作 (最前面、全画面、フレーム/タイトル非表示、サイズプリセット、アスペクト比)
- 音量、スナップショット
- 右クリックメニュー / キーボードショートカット (PCRPlayer 互換)
- スレ一覧ウィンドウ (別ウィンドウ表示)

詳細は [`features.md`](../features.md) を参照。

## オミットする機能 (PCRPlayer にはあるが PSTPlayer では実装しない)

| 機能                                       | オミット理由                                                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| **ローカルファイル/URL 直接再生**          | PSTPlayer のスコープ外。ローカル動画なら mpv 本体や VLC を使えばよい           |
| **オフライン再生メニュー**                 | 同上                                                                          |
| **シークバー**                             | PeerCast はライブストリーミングのためシーク不可。オフライン専用要素           |
| **シークバーにファイル名表示**             | シークバー自体がないため不要                                                  |
| **ステータスバーで時間を可変表示 (オフライン)** | ローカルファイル再生の現在時刻/総時間表示用。オンラインでは配信時間表示で代替 |
| **フィルタグラフ メニュー**                | DirectShow 固有の概念。libmpv では不要                                        |
| **実行優先度メニュー**                     | Windows プロセス優先度の制御。クロスプラットフォームでは扱いが OS 依存になり過剰 |
| **レジストリ設定**                         | クロスプラットフォーム不可。設定ファイル (TOML) に統一                        |
| **内蔵 BBS ブラウザ (IE 埋め込み / DHTML)** | 廃止技術。Tauri の WebView を活用した HTML 表示モードに置き換えるか単一の BBS ペインに統合 |

## 将来再検討する可能性のあるもの

スコープ外だが、需要が出れば検討:

- **ローカル動画再生 / シーク** — VOD アーカイブ視聴需要が出た場合
- **録画機能** — mpv の `stream-record` で技術的には容易
- **リモート操作** — 別端末からの視聴制御
- **複数同時再生** — ピクチャ・イン・ピクチャ等

これらは v1.0 以降の検討事項として [`roadmap.md`](../roadmap.md) のフェーズ 4 に整理する。

## 根拠

- **ユースケースの明確化**: 「PeerCast 視聴 + BBS」に絞ることで、UI / 設定 / コードベースの複雑度を抑える
- **クロスプラットフォーム対応の現実性**: Windows 固有概念 (DirectShow フィルタ、プロセス優先度) はオミットすることで 3 OS 対応の実装コストを下げる
- **メンテナビリティ**: 機能を絞ることで小規模チーム / 個人での継続的メンテが可能
- **PCRPlayer ユーザーの移行体験**: オンライン機能だけでも PCRPlayer ユーザーの主要ユースケースは満たせる
