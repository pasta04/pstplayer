# ショートカット一覧

すべて設定 → ショートカット タブでカスタマイズ可能 (固定キーを除く)。
カスタマイズしたものは `config.toml` の `[hotkeys]` セクションに保存
されます。

> 開発者向け / プロトコル仕様の側面は [`docs/shortcuts.md`](../shortcuts.md) を参照。

---

## 表示パーツ ON/OFF (PCRPlayer 互換、単キー)

| キー | 動作                       |
| ---- | -------------------------- |
| T    | 常に最前面 ON/OFF          |
| Z    | ウィンドウ枠 (装飾) ON/OFF |
| X    | タイトル帯 ON/OFF          |
| B    | ステータスバー ON/OFF      |
| C    | BBS ペイン ON/OFF          |

> テキスト入力中 (書き込み欄 / 検索欄) はホットキーが無効化されるので、
> `t` や `z` などの文字を打っても誤動作しません。

## プレイヤー

| キー        | 動作                                          |
| ----------- | --------------------------------------------- |
| F11         | 全画面切替                                    |
| Alt+Enter   | 全画面切替 (PCRPlayer 互換、固定)             |
| Esc         | 全画面解除 (固定、テキスト入力中も効く)       |
| F5          | 再接続 (Bump)                                 |
| Ctrl+F5     | 切断 (Stop)                                   |
| F2          | スナップショット                              |
| ホイール    | 音量上下 (動画エリア上で。5% 刻み、0-150%)    |

## サイズプリセット (固定、カスタマイズ不可)

`Ctrl + 数字キー`:

| キー    | サイズ |
| ------- | ------ |
| Ctrl+1  | 50%    |
| Ctrl+2  | 75%    |
| Ctrl+3  | 100%   |
| Ctrl+4  | 125%   |
| Ctrl+5  | 150%   |
| Ctrl+6  | 175%   |
| Ctrl+7  | 200%   |
| Ctrl+8  | 250%   |
| Ctrl+9  | 300%   |

ベースサイズは現在の動画の解像度 (`video-params/w` × `h`)。取得前は
1280x720 を仮定します。

| ------ | ---------- |

| Alt+2  | 16:9       |
| Alt+3  | 4:3        |
| Alt+4  | 16:10      |

## BBS / ナビゲーション

| キー           | 動作                                    |
| -------------- | --------------------------------------- |
| Ctrl+R         | スレ差分更新                            |
| Ctrl+Shift+R   | スレ完全再取得 (キャッシュ破棄)         |
| Ctrl+F         | スレ内検索フィルタにフォーカス          |
| Ctrl+L         | スレ一覧サブウィンドウを開く            |
| Ctrl+V         | クリップボードの URL を貼り付け → 再生 |
| Ctrl+,         | 設定ウィンドウを開く                    |
| Ctrl+Enter     | 書き込み送信 (設定で Shift+Enter に変更可) |

> 書き込み欄での `Enter` は常に改行です。

## カスタマイズ

設定 → ショートカット タブ:

1. 行末の **変更** ボタンを押す
2. 「⌨ 待機中…」になったら割り当てたいキーを押す
3. 自動的に記録されてキャプチャ終了
4. `Esc` でキャプチャをキャンセル
5. 衝突 (同じキーに複数アクション) があれば赤い行 + 警告

その他の操作:

- **無効** ボタン: そのアクションのキー割当を消す (= ホットキー無効化)
- **初期** ボタン: そのアクションをデフォルトキーに戻す

設定の保存ボタンを押すと、メインウィンドウに即時反映 (再起動不要)。
