# 初回セットアップ

インストール直後にやるべき設定をまとめます。すべて **設定ウィンドウ**
(右クリックメニュー → `⚙ 設定...` または `Ctrl+,`) から行います。

設定は OS 標準の場所に `config.toml` として保存されます:

| OS      | 場所                                                |
| ------- | --------------------------------------------------- |
| Windows | `%APPDATA%\PSTPlayer\config.toml`                   |
| macOS   | `~/Library/Application Support/PSTPlayer/config.toml` |
| Linux   | `~/.config/PSTPlayer/config.toml`                   |

> 設定ウィンドウの「一般」タブに上記のパスが表示されています。手で
> 直接編集することも可能です。

---

## 1. PeerCast の接続先 (必須)

**設定 → PeerCast** タブ

| 項目                | 説明                                                                         |
| ------------------- | ---------------------------------------------------------------------------- |
| ホスト              | PeerCast 本体が動いているマシン。同一 PC なら `localhost`                    |
| ポート              | 既定 `7144` (PeerCastStation のデフォルト)                                   |
| Basic 認証 ユーザー | リモート接続 (LAN 内別マシン) で PeerCastStation の認証を有効にしている場合 |
| Basic 認証 パスワード | 同上                                                                         |
| 接続タイムアウト    | 既定 5 秒                                                                    |

設定 → 保存 すると、最近使ったホスト (recent_hosts) としても記録され、
次回以降のクリックで切り替え可能になります (LAN 内で複数の
PeerCastStation を運用しているケース向け)。

## 2. YP の URL (任意)

**設定 → YP** タブ

PeerCast の Yellow Page (中央配信一覧) の `index.txt` URL を登録すると、
右クリック → `📡 YP チャンネル一覧` または **ハブ画面**
([hub.md](hub.md)) で配信中チャンネルを一覧表示し、クリックで即視聴
できます。

複数 YP を並行に取得できるので、まず `[[yp.sources]]` テーブルから
追加してください:

| 項目     | 内容                                              |
| -------- | ------------------------------------------------- |
| 名前     | UI 表示用 (タブのラベル)                          |
| 名前空間 | PeCaRecorder 互換 (任意)                          |
| URL      | YP の `index.txt` の絶対 URL (`http(s)://` のみ) |
| タブ表示 | ハブのタブバーにこの YP を出すか                  |
| すべて   | 「すべて」タブにこの YP を含めるか                |
| 背景色   | このタブの下線色 / お気に入り未マッチ行のデフォルト |
| 文字色   | デフォルト文字色                                  |

空のままでも URL 貼り付けでの視聴は可能です。

## 3. BBS 書き込み欄のデフォルト (任意)

**設定 → BBS** タブ

| 項目                  | 既定           | 説明                                 |
| --------------------- | -------------- | ------------------------------------ |
| デフォルト名前        | (空)           | 「名無しさん」のままで良ければ空     |
| デフォルトメール      | `sage`         | sage 進行が標準                       |
| 自動更新間隔 (秒)     | 5              | スレを開いている間の差分取得間隔      |
| 表示モード            | プレーン       | HTML モードにすると装飾タグが反映される |
| 書き込み欄の送信キー  | Ctrl/Cmd+Enter | Shift+Enter に変更可                  |
| 新着レス時の自動スクロール | ON         | 末尾にいる時だけ追従、手動スクロール時は止まる |

## 4. プレイヤー (任意)

**設定 → プレイヤー** タブ

| 項目                   | 既定 | 説明                                              |
| ---------------------- | ---- | ------------------------------------------------- |
| 初期音量               | 80   | 起動時のボリューム (0-100)                        |
| スナップショット保存先 | 空   | 空なら exe 配下の `snapshot/` フォルダ            |
| スナップショット形式   | png  | png / jpg                                         |
| JPEG 画質              | 95   | jpg 選択時のみ有効                                |
| 録画の保存先           | 空   | 空なら exe 配下の `recordings/` フォルダ          |
| 録画ファイル拡張子     | 空   | 空なら `flv`。`mkv` 等にも変更可。libmpv がコンテナを推測 |

保存先が書き込み不可だった場合 (`.app` バンドル内 / AppImage 内 /
`Program Files` 配下で権限なし等)、OS 標準の Pictures (snapshot) / Videos
(録画) フォルダ配下 `PSTPlayer/` にフォールバックします。

## 5. お気に入り (任意)

**設定 → お気に入り** タブ

複数のルールを定義してハブ画面と YP 一覧で行を強調表示できます。

| フィールド    | 内容                                                            |
| ------------- | --------------------------------------------------------------- |
| 名前          | UI 表示用の識別子                                               |
| チャンネル名 / ジャンル / 詳細 / コメント | 部分一致 (大文字小文字無視)。空欄ワイルドカード、複数指定 AND。`a|b|c` で OR |
| ⬆ pin_top     | チャンネル一覧で上位固定                                        |
| ⏺ auto_record | 視聴開始時 / pst-server 常駐時に自動録画                        |
| 動作          | `表示` / `非表示` / `ブロック`                                  |
| 背景色 / 文字色 | 行の CSS 色 (例: `#9be8df` / `lightgreen` / `#ff8a3d22`)      |

ルールは上から順に評価され、最初にマッチしたものが採用 (`first match`
セマンティクス)。具体的なルールほど上位に置いてください。

## 6. ハブ画面 (任意)

**設定 → YP** タブ末尾の「ハブ画面の更新間隔」セクション

| 項目                            | 既定       | 内容                                                |
| ------------------------------- | ---------- | --------------------------------------------------- |
| YP 自動再 fetch 間隔 (秒)       | 60         | 全 YP の `index.txt` を並行に取り直す。0 で無効     |
| 「視聴中」ポーリング間隔 (秒)   | 5          | single_instance ロックを舐めて視聴中バッジを更新    |
| ダブルクリックの動作            | 視聴       | 視聴 / 視聴+録画 / BBS / ブラウザ / 何もしない      |
| ミドルクリックの動作            | BBS を開く | 同上                                                |
| pst-server URL                  | `http://localhost:8080/` | 🌐 ボタンで開く先 |

詳細は [hub.md](hub.md) を参照。

## 7. ショートカット (任意)

**設定 → ショートカット** タブ

15 アクションすべてキーをカスタマイズできます。各行の「変更」を押した
後、割り当てたいキーを押せばそのまま記録されます (`Esc` でキャンセル)。
衝突 (同じキーに複数アクション) があると赤く警告が出ます。

> `Ctrl+1〜9` (サイズ) / `Alt+1〜7` (アスペクト比) / `Esc` (全画面解除)
> はカスタマイズ不可です。

詳細は [ショートカット一覧](shortcuts.md) を参照。
