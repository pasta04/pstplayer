# トラブルシューティング

## 起動関連

### Windows で「mpv.dll が見つかりません」「libmpv-2.dll が見つかりません」

ZIP に同梱された `libmpv-2.dll` は `pstplayer.exe` と**同じフォルダ**
に置く必要があります。デスクトップショートカット経由で起動している
場合は、ショートカットのプロパティで「作業フォルダー」が exe の場所に
なっていることを確認してください。

### Windows SmartScreen で「Windows によって PC が保護されました」

未署名のため警告が出ます。「**詳細情報**」→「**実行**」で起動可能。
このダイアログは初回起動時のみ。

### macOS で「開発元未確認のため開けません」

Cmd + クリック → 「開く」で 1 回開けばその後は通常起動できます。
毎回出るのが煩わしい場合:

```bash
xattr -dr com.apple.quarantine /Applications/PSTPlayer.app
```

### Linux Wayland で動画が真っ黒のまま音だけ出る

現在のところ Wayland セッションでは libmpv のネイティブウィンドウ
埋め込み (wid) が利用できません。X11 セッションで起動してください。

## PeerCast 接続関連

### 「PeerCast に接続できません」と出て YP / 再生開始ができない

設定 → PeerCast でホスト / ポートが正しいか確認:
- PeerCastStation のデフォルトは `localhost:7144`
- LAN 内の別マシンで動かしている場合はそのマシンの IP を指定
- ファイアウォール (Windows Defender / iptables) で 7144 が通っているか確認
- PeerCastStation 側で **「外部からの接続を許可」** にチェックが入っ
  ているか (LAN 接続時)

設定の保存後、メインウィンドウから `Ctrl+,` で開き直してから再度
起動するか、右クリック → `📡 YP チャンネル一覧` で再試行してください。

### PeerCastStation で Basic 認証を有効にしている

設定 → PeerCast → 「Basic 認証」のユーザー / パスワードに
PeerCastStation の HTML UI 用認証情報を入れてください。これがないと
JSON-RPC が 401 で弾かれます。

## BBS 関連

### 書き込みボタンを押しても送信できない / エラーになる

ステータスバーに表示されるエラーで原因を切り分けます:

- **「書き込みが規制されています」**: ホスト規制 / 連投規制 / プロバ
  規制 / 巻き込まれ規制 等です。BBS 側の規制なので時間を置くか
  プロバイダ環境を変える必要があります。
- **「書き込みが拒否されました」**: 規制以外の拒否 (Cookie 確認失敗 /
  フォーム改変 等)。ブラウザで一度書き込んで Cookie 確認画面を
  通過してから再度試すと通る場合があります。
- **「PeerCast に接続できません」**: BBS ではなく PeerCast 本体への
  接続の問題。上の節を参照。

### スレタイトル帯に「💀 落ち」と表示される

dat / rawmode が 404 / 410 を返した = スレが削除された or 過去ログ
送りになった、ということです。自動更新は止まります。`Ctrl+Shift+R`
で再試行できますが、同じエラーが続く場合はスレッド一覧から別スレを
選んでください。

### URL に `/l30` が付いていて動かない / 全レス取れない

`/l30` (最新 30 件) / `/501-1000` (範囲) 等のサフィックスが付いていても
全レス取得 + 差分更新は正常に動きます (内部で `/{key}/` に正規化)。
動かない場合は別の原因です。エラーメッセージを確認してください。

## プレイヤー関連

### 動画は出るが音が出ない / 出るが小さい

- ホイールで音量を上げてみる (ステータスバー右端に音量が表示されます)
- OS のミキサーで PSTPlayer がミュートされていないか確認
- 音量上限は 150% まで上げられます (settings → プレイヤー → 初期音量)

### 動画のサイズが小さい / 大きすぎる

- `Ctrl+1〜9` でサイズプリセット
- 右クリック → `📐 サイズ ▶` でも同じ
- アスペクト比がおかしい場合は `Alt+1〜7` または右クリック → `📺 アスペクト比 ▶`

### スナップショットを撮ってもファイルが見つからない

- 設定 → プレイヤー → 「スナップショット保存先」の表示パスを確認
- 空欄なら exe と同じフォルダの `snapshot/` サブフォルダ
- 1 秒以内に連発した場合は OS 通知が最後の 1 件にまとめられて出ます

### 録画ファイルがどこに出来たか分からない

- 設定 → プレイヤー → 「録画の保存先」の表示パスを確認
- 空欄なら exe と同じフォルダの `recordings/` サブフォルダ
- ファイル名は `YYYYMMDD_HHmmss_<channel_name>.<ext>` (拡張子は設定 →
  「録画ファイル拡張子」、空なら `flv`)
- 録画中に右クリック → `⏺ 録画停止` を hover すると現在のパスが
  tooltip に表示されます

### 録画ファイルが他のプレイヤーで再生できない

- FLV / MKV は途中で切断されても多くのプレイヤーで再生できますが、
  MP4 等の moov-atom-終端形式は途中切断で再生不能になることがあります。
  `recording_ext` は既定の `flv` のままにするか `mkv` を推奨
- VLC や mpv のように寛容なプレイヤーで開いてみてください

## ハブ画面関連

### ハブ画面が真っ白 / YP が出ない

- 設定 → YP タブで `[[yp.sources]]` に少なくとも 1 つ URL を登録
  (`http://` または `https://` で始まる絶対 URL のみ受け付けます)
- ステータス帯に「YP X: 取得失敗」が出ていないか確認。expandable で
  詳細を展開できます

### 同じチャンネルを 2 度開いてもウィンドウが増えない

仕様です。`channel_id` 単位で single_instance ロックを取っているため、
既に視聴中のチャンネルを開こうとすると既存ウィンドウにフォーカスが
当たります。本当に別ウィンドウで開きたい場合はそのチャンネルを別 ID
で配信し直す or 既存ウィンドウを閉じてから再度開いてください。

### 「視聴中」タブが古い情報のまま更新されない

- 設定 → YP → 「ハブ画面の更新間隔」→「視聴中ポーリング間隔」が 0 に
  なっていると更新されません。既定 5 秒へ戻してください
- ロックファイル (`$TMPDIR/pstplayer-locks/ch-*.lock`) が stale な
  ままの場合、次回ポーリング時に死亡判定 + 自動削除されます

### 「✕ 全閉じ」を押しても閉じないウィンドウがある

ウィンドウが応答しない場合、IPC `close\n` が届かず無視されます。
OS のタスクマネージャ / `kill` で強制終了してください。stale lock は
次回ハブ起動時に自動掃除されます。

## 設定 / 設定ファイル

### 設定が保存されない

config.toml の保存場所:

| OS      | 場所                                                |
| ------- | --------------------------------------------------- |
| Windows | `%APPDATA%\PSTPlayer\config.toml`                   |
| macOS   | `~/Library/Application Support/PSTPlayer/config.toml` |
| Linux   | `~/.config/PSTPlayer/config.toml`                   |

該当フォルダの書き込み権限があるか確認してください。Antivirus が
ブロックしている場合もあります。

### config.toml が壊れた

起動時にパースエラーが出る形になると、PSTPlayer は同じディレクトリに
`config.toml.bak.YYYYMMDD_HHMMSS` でバックアップを取って、デフォルト
設定で起動します。バックアップは手で開いて編集→上書きすれば復旧可能。

### 設定をリセットしたい

PSTPlayer を終了 → 上記の `config.toml` を削除 → 再起動。

## それ以外

不具合報告 / 機能要望は
[GitHub Issues](https://github.com/pasta04/pstplayer/issues) へ。報告
時は以下を添えていただけると助かります:

- OS とバージョン (Windows 11 / macOS 14.4 / Ubuntu 24.04 等)
- PSTPlayer のバージョン (タイトルバー or 設定 → 一般 タブの設定
  ファイル パス)
- PeerCast 本体の種類とバージョン (PeerCastStation 3.x など)
- 再現手順
- スクリーンショット / ステータスバーのエラーメッセージ
