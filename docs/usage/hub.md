# Desktop ハブ画面の使い方

`pstplayer` を URL 引数なしで起動すると、PeCaRecorder 風の **ハブ画面**
(YP テーブル + お気に入り + 視聴管理) が表示されます。

URL 引数つきで起動 (`pstplayer http://.../pls/{id}`) した場合は従来の
単体プレイヤー UI (動画 + BBS ペイン) が出ます。

## ツールバー (上部)

- **↻ 更新** — 全 YP を再 fetch
- **🔗 URL から開く** — PeerCast URL を prompt で入力して直接視聴
- **⚙ 設定** — 設定ダイアログ
- **✕ 全閉じ (N)** — 開いている全視聴ウィンドウを一括クローズ
  (N は現在の視聴中数)。0 の時は disabled

## 主な機能

- **複数 YP**: 設定の YP タブで何個でも YP を登録可。各 YP の `index.txt`
  を並行にフェッチし、`channel_id` が重複した場合は **上にある YP の
  もの** を採用
- **お気に入りルール**: 設定の お気に入り タブで条件 + 表示色 + 動作を
  ルール化。マッチした行は背景色 / 文字色を変えたり、上位に固定 (★)、
  自動録画フラグの設定もできる
- **タブ**: すべて / お気に入り / 新着 / 視聴中、加えて各 YP のタブ
- **ソート**: カラムヘッダクリックで昇順 ▲ / 再クリックで降順 ▼。
  既定はリスナー降順。`pin_top` のお気に入りは常に最上位に固定
- **フィルタ**: ツールバーの入力欄に絞り込み文字列を入れると、名前 /
  ジャンル / 詳細 / コメント / YP 名 のいずれかに含まれる行だけ表示
- **新着通知**: 自動再 fetch で新規出現したお気に入りマッチを OS 通知
- **視聴ウィンドウ**: 行ダブルクリック / Enter / 右クリ > 視聴 で
  `pstplayer.exe <url>` を別プロセスで起動。同じチャンネルは 2 度
  開かない (既存ウィンドウにフォーカス)

## キーボードショートカット

| キー            | 動作                                  |
| --------------- | ------------------------------------- |
| `F5` / `Ctrl+R` | YP を再取得                           |
| `Ctrl+F`        | フィルタ入力欄にフォーカス            |
| `↑` / `↓`     | 選択行を移動 (画面内にスクロール)     |
| `Enter`         | 選択行を視聴 (別ウィンドウ)           |
| `Shift+Enter`   | 選択行を視聴 + 録画開始               |
| `Esc`           | コンテキストメニューを閉じる          |

## 右クリックメニュー

| 項目                                   | 動作                                        |
| -------------------------------------- | ------------------------------------------- |
| ▶ 視聴 (別ウィンドウで開く)            | `pstplayer.exe <url>` を spawn              |
| ⏺ 視聴 + 録画開始                      | spawn 時に `--record-on-start` を付与       |
| ✕ 視聴ウィンドウを閉じる               | 視聴中の行のみ表示 (close IPC を送信)       |
| 📺 BBS としてコンタクト URL を開く     | スレ一覧ウィンドウを開く                    |
| 🌐 コンタクト URL をブラウザで開く     | OS のデフォルトブラウザで開く               |
| ★ お気に入りルールに追加…             | 設定 → お気に入りタブを開き、新規ルール追加 |
| 📋 コピー > チャンネル名 / 詳細 / etc. | クリップボードへ                            |

## お気に入りルール

設定 → お気に入り タブで複数行のテーブルとして編集します。

| フィールド    | 内容                                                            |
| ------------- | --------------------------------------------------------------- |
| 名前          | UI 表示用の識別子                                               |
| チャンネル名  | 部分一致パターン (大文字小文字無視)。`a|b|c` で OR              |
| ジャンル      | 同上                                                            |
| 詳細          | 同上                                                            |
| コメント      | 同上                                                            |
| ⬆ pin_top     | チャンネル一覧で上位固定                                        |
| ⏺ auto_record | 自動録画 (pst-server 同居運用時)                                |
| 動作          | `表示` / `非表示` / `ブロック`                                   |
| 背景色        | 行の背景 CSS 色 (例: `#9be8df` / `lightgreen` / `#ff8a3d22`)     |
| 文字色        | 行の文字 CSS 色 (例: `#ffffff`)                                  |

ルールは上から順に評価され、最初にマッチしたものが採用 (`first match`
セマンティクス)。ブロックルールを上位に置けば、後続の自動録画ルール
が当たっても録画されません。

## 自動更新間隔

設定 → YP タブ末尾の「ハブ画面の更新間隔」セクションで調整できます:

| 設定                            | 既定 | 内容                                                |
| ------------------------------- | ---- | --------------------------------------------------- |
| YP 自動再 fetch 間隔 (秒)      | 60   | 全 YP の `index.txt` を並行に取り直す。0 で無効     |
| 「視聴中」ポーリング間隔 (秒) | 5    | single_instance ロックを舐めて視聴中バッジを更新。0 で無効 |

両方とも保存と同時にハブ側へ反映されます (`config:saved` イベント
経由)。手動更新は `F5` / `Ctrl+R` で常に可能です。

## YP ソース設定

設定 → YP タブで複数 YP を登録します。

| フィールド   | 内容                                                            |
| ------------ | --------------------------------------------------------------- |
| 名前         | UI 表示用 (タブのラベルにもなる)                                |
| 名前空間     | PeCaRecorder 互換 (任意)                                        |
| URL          | YP の `index.txt` の絶対 URL                                    |
| タブ表示     | ハブのタブバーにこの YP のタブを出すか                          |
| すべて       | 「すべて」タブにこの YP のチャンネルを含めるか                  |
| 背景色       | このタブの下線色 / お気に入り未マッチ行のデフォルト背景         |
| 文字色       | デフォルト文字色                                                |

旧 `peercast.yp_url` 単体設定もそのまま残っていますが、`[[yp.sources]]`
に 1 件でも登録するとそちらは無視されます (移行用)。

## なぜ複数 YP は直接 fetch なのか

`PeerCastStation` には「YP に登録されている全チャンネル」を返す API が
ありません (`getChannels` は **PeerCast 自身がリレー / ブロードキャスト
中** のチャンネルしか返さない)。したがってハブ画面で「YP に出ている全
配信」を見るには、各 YP の `index.txt` を直接 HTTP GET する以外の手段
が無く、PeCaRecorder と同じアプローチを取っています。

## 視聴ウィンドウとの関係

ハブから「視聴」した時に開くウィンドウは **別の `pstplayer.exe` プロセス**
です (同居運用の Web グリッドとは別物)。理由:

- クラッシュ耐性 (1 視聴ウィンドウが落ちても他に波及しない)
- OS のタイル / 仮想デスクトップ / マルチモニタを活かせる
- libmpv は 1 プロセス 1 インスタンス想定でシンプル

詳細は [ADR-0006](../decisions/0006-auto-record-and-multiview.md) を参照。
