# 基本操作

本書は **URL 引数つきで起動** したビューア画面 (動画 + BBS ペイン) の
操作を扱います。`pstplayer` を **引数なしで起動** するとハブ画面
(PeCaRecorder 風の YP テーブル + 視聴管理) が出ます — そちらの操作は
[hub.md](hub.md) を参照してください。

## チャンネル視聴を始める

### 方法 1: URL 貼り付け

1. ブラウザの PeerCast 配信ページから `pls` URL をコピー
   (例: `http://localhost:7144/pls/0123456789ABCDEF...`)
2. PSTPlayer のメインウィンドウ中央の **URL 入力欄** に貼り付け
3. `Open` ボタンを押す (または `Ctrl+V` でクリップボードから直接ペースト
   → 自動でこの欄に流し込まれる)

### 方法 2: YP チャンネル一覧から

1. 右クリック → `📡 YP チャンネル一覧` (起動時に PeerCast が起動して
   いれば自動で開きます)
2. リストから視聴したいチャンネルをクリック
3. 自動で再生開始

### 方法 3: 視聴履歴から

右クリック → `🕒 視聴履歴 ▶` の中から選択。最近 12 件まで表示されます。

### 方法 4: コマンドライン引数 (外部ツール連携)

```bash
pstplayer http://localhost:7144/pls/<channel_id>
```

PCRPlayer 互換の引数形式 (チャンネル名 / id / tip / contact / genre /
desc / bitrate 等を渡せる) もサポートします。`pstplayer --help` で
全引数一覧を表示。

`--no-autoplay` を付けると自動再生せず URL だけ受け取ります。

## 再生中の操作

### 動画エリア

| 操作              | 動作                                       |
| ----------------- | ------------------------------------------ |
| ホイール          | 音量上下 (5% 刻み、0-150%)                 |
| ダブルクリック    | 全画面切替                                 |
| 右クリック        | コンテキストメニュー                       |

### 右クリックメニュー

- ↻ **再接続 (Bump)** / ■ **切断 (Stop)** — F5 / Ctrl+F5 と同等
- ⛶ **全画面切替** — F11 と同等
- ✓ **常に最前面** — T と同等 (チェック表示で状態が分かる)
- 🔗 **コンタクト URL を開く** — 配信元の BBS URL を OS 既定ブラウザで開く
- 📋 **チャンネル URL をコピー**
- 📊 **チャンネル詳細...** — ChannelInfo / ChannelStatus / 解像度 / FPS
  をモーダルで一覧
- 📐 **サイズ ▶** — 50% / 75% / 100% / 125% / ... / 300% (Ctrl+1〜9 同等)
- 📺 **アスペクト比 ▶** — 自動 / 16:9 / 4:3 / 16:10 / 5:4 / 2.35:1 /
  ストレッチ (Alt+1〜7 同等)
- 🕒 **視聴履歴 ▶** — 最近開いたチャンネルから再開
- 📷 **スナップショット (F2)** — 現在のフレームを png/jpg で保存
- ⚙ **設定...**
- ≡ **スレ一覧を開く** — コンタクト URL の板のスレ一覧サブウィンドウ
- 📡 **YP チャンネル一覧**

## BBS の読み書き

### スレを開く

PeerCast チャンネルのコンタクト URL が **スレ URL 直指定** (例:
`https://jbbs.shitaraba.net/bbs/read.cgi/.../1234/`) なら、視聴開始と
同時にそのスレが右側 BBS ペインに自動表示されます。

**板トップ URL** (例: `https://jbbs.shitaraba.net/computer/4567/`) の
場合は、右クリック → `≡ スレ一覧を開く` でスレ一覧サブウィンドウを
表示 → クリックで選択します。

### レス一覧

| 操作            | 動作                                                    |
| --------------- | ------------------------------------------------------- |
| `>>123` クリック | 該当レスをポップアップで表示                            |
| ID クリック     | 同一 ID のレスをポップアップで抽出                       |
| URL クリック    | OS 既定ブラウザで開く                                    |
| レス番号クリック | 書き込み欄に `>>123` を挿入                              |

### 絞り込み (フィルタ)

`Ctrl+F` でレス一覧上部のフィルタ欄にフォーカス。特殊構文をサポート:

| 入力           | 効果                                                       |
| -------------- | ---------------------------------------------------------- |
| `(普通の文字列)` | 本文 / 名前 / ID / 番号 を横断検索                          |
| `>>123`        | レス番号 123 を中心に前後 2 件を抽出                         |
| `>>120-130`    | レス番号 120-130 と前後 2 件を抽出                           |
| `id:abc123`    | ID が `abc123` を含むレスを抽出                              |

### 書き込み

1. レス一覧下部の書き込み欄に本文を入力
2. **Ctrl+Enter** (または設定で Shift+Enter に変更可) で確認ダイアログ
3. 「OK」で送信

書き込み中の Enter は通常の改行になります。`>>123` 等のアンカーは
レス番号クリックで自動挿入できます。

### 自動更新

スレを開いている間、デフォルト 5 秒間隔で差分取得します (`If-Modified-Since` /
`Range: bytes=N-` で軽量化)。次回更新までの秒数はスレタイトル帯の
右端 `↻ Ns` で確認できます。

- `Ctrl+R` — 即時差分更新
- `Ctrl+Shift+R` — キャッシュ破棄 → 全レス再取得

### スレが落ちた時

dat / rawmode が 404 / 410 を返すと、スレタイトル帯に **💀 落ち** と
表示され自動更新が停止します。`Ctrl+Shift+R` で再試行可能。

## お気に入り

設定 → お気に入り タブで複数のルールを定義できます。各ルールは
YP チャンネル一覧 / PeerCast チャンネル一覧に対して上から評価され、
最初にマッチしたものが採用されます。

| 項目 | 動作 |
|---|---|
| 名前 | 識別用ラベル (マッチには使わない) |
| チャンネル名 / ジャンル / 詳細 / コメント | 部分一致 (大文字小文字無視)、空欄ワイルドカード、複数指定 AND |
| ⬆ 上位固定 | YP テーブルでこのルールにマッチした行を上に固定 |
| ⏺ 自動録画 | 視聴開始時に自動で録画を開始 (Desktop は 1 本まで) |
| 色 | 行の背景色 (CSS 色)。`#ff8a3d22` のように `alpha` を含められる |

ルールの並び順 (↑ / ↓ ボタン) が優先順位になります。具体的なルールを
上に置く運用にしてください。

## 録画

右クリック → `⏺ 録画開始` で視聴中の配信をファイルに保存します。
録画中はメニュー項目が `⏹ 録画停止` に変わり、もう一度押すと停止。

- **再エンコードしません**。libmpv の `stream-record` 機能で元
  コンテナ (FLV/MKV 等) をそのままディスクに書き出すため CPU 負荷
  ほぼゼロ
- 保存先: 設定 → プレイヤー → 「録画の保存先」 (空なら exe 配下
  `recordings/` フォルダ)
- ファイル名: `YYYYMMDD_HHmmss_<channel_name>.<ext>`
  拡張子は設定 → 「録画ファイル拡張子」 (空なら `flv`)
- 録画中はメニュー項目が「⏹ 録画停止」になり、tooltip に出力中の
  パスが出ます
- 配信が終了する / 接続が切れる / アプリを閉じると自動で録画も終了

> ⚠ FLV / MKV は途中で切れても多くのプレイヤーで再生できますが、
> MP4 等の moov-atom-終端形式は途中切断で再生不能になることがあります。

## スナップショット

`F2` または 右クリック → `📷 スナップショット` で現在のフレームを
保存。

- 保存先: 設定 → プレイヤー → 「スナップショット保存先」 (空なら
  exe 配下 `snapshot/` フォルダ)
- ファイル名: `YYYYMMDD_HHmmss_<channel_name>.png` (jpg 設定時は .jpg)
- 1 秒以内に連発した場合は OS 通知が最後の 1 件にまとめられます

## ウィンドウ表示の切り替え

ホットキーでパーツの表示を切り替えできます (PCRPlayer 互換):

| キー | 効果                       |
| ---- | -------------------------- |
| T    | 常に最前面 ON/OFF          |
| Z    | ウィンドウ枠 (装飾) ON/OFF |
| X    | タイトル帯 ON/OFF          |
| B    | ステータスバー ON/OFF      |
| C    | BBS ペイン ON/OFF          |

---

## 終了

ウィンドウを閉じれば終了します。次回起動時は最後のウィンドウ位置 /
サイズが復元されます (メインウィンドウのみ)。
