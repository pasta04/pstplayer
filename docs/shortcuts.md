# キーボードショートカット一覧

PCRPlayer 互換のキー割り当てを基本とする。すべて設定でカスタマイズ可能。

## 1. 表示要素の ON/OFF

PCRPlayer 互換。右クリックメニューの「表示」配下と同じトグル。

| キー | 機能              |
| ---- | ----------------- |
| T    | 最前面表示        |
| Z    | フレーム (枠)     |
| X    | タイトルバー      |
| B    | ステータスバー    |
| C    | BBS ペイン        |

## 2. プレイヤー操作

| キー                  | 機能                          |
| --------------------- | ----------------------------- |
| Enter / Alt+Enter / F11 | 全画面切替                  |
| Esc                   | 全画面解除                    |
| Space                 | 再生 / 一時停止 (緊急用)      |
| ↑ / ↓                 | 音量 +1 / −1                  |
| Shift + ↑ / ↓         | 音量 +5 / −5                  |
| M                     | ミュート切替                  |
| Ctrl + 1〜9           | サイズプリセット (50%〜200%)  |
| Alt + 1〜7            | アスペクト比切替              |

`Space` (再生/停止) はライブ視聴では通常使わないため、緊急時 (リレー再構築失敗) の最終手段 ([ADR-0004](decisions/0004-scope.md))。

## 3. チャンネル操作

| キー        | 機能                              |
| ----------- | --------------------------------- |
| F5          | 再接続 (Bump)                     |
| Ctrl + F5   | 切断 (Stop)                       |
| Ctrl + V    | クリップボード URL を貼り付け再生 |
| Ctrl + C    | チャンネル URL をコピー           |
| Ctrl + I    | チャンネル情報ダイアログを開く    |

## 4. BBS 操作

| キー              | 機能                                 |
| ----------------- | ------------------------------------ |
| Ctrl + Enter      | 書き込み送信 (確認ダイアログ経由)    |
| Ctrl + R          | 現在スレを再取得 (差分)              |
| Ctrl + Shift + R  | 現在スレを完全再取得 (差分破棄)      |
| Ctrl + F          | スレ内キーワード検索                 |
| Ctrl + L          | スレ一覧ウィンドウを開く             |
| Ctrl + Shift + C  | コンタクト URL をコピー              |

## 5. ウィンドウ / アプリケーション

| キー        | 機能                            |
| ----------- | ------------------------------- |
| Ctrl + ,    | 設定ダイアログを開く            |
| F1          | バージョン情報を表示            |
| Ctrl + Q    | アプリケーション終了            |

## カスタマイズ

- 設定ダイアログの「ショートカット」タブで全項目を再割り当て可能
- 競合検出: 同じキーを 2 つの機能に割り当てると警告
- リセット: 「デフォルトに戻す」ボタンで初期状態へ
- 設定は `config.toml` の `[shortcuts]` セクションに保存

## OS 別の修飾キー

| 表記         | Windows / Linux | macOS                |
| ------------ | --------------- | -------------------- |
| `Ctrl`       | Ctrl            | Cmd (⌘)              |
| `Alt`        | Alt             | Option (⌥)           |
| `Shift`      | Shift           | Shift (⇧)            |

設定保存時は OS 非依存の論理キー名 (`Mod+V` 等) で保持し、表示時に各 OS の慣習へ変換する。
