# UI デザイン

PSTPlayer のメインウィンドウのレイアウトとインタラクション仕様。

> **画像**: `docs/images/main-layout.png` に元案のスクリーンショットを配置予定 (オーナーから提供された設計案)。

## メインウィンドウ レイアウト

```
┌───────────────────────────────────────────┬───────────────┐
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │   レス一覧    │
│              配信画面 (動画)              │     表示      │
│                 (libmpv)                  │   (BBS pane)  │ scrollbar
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │               │
├───────────────────────────────────────────┴───────────────┤
│ スレッドタイトル (件数)                                   │  ← オレンジ帯
├───────────────────────────────────────────────────────────┤
│ 書き込みテキストボックス                                  │  ← 黒帯 (可変高)
│ (Enter で改行 → 自動で下に広がる)                         │
├───────────────────────────────────────────────────────────┤
│ チャンネル名  受信bps/最大bps  (現在fps/最大fps)          │  ← 緑帯 (ステータス)
└───────────────────────────────────────────────────────────┘
```

### 各エリアの役割

| エリア                | 色 (案) | 内容                                                                            |
| --------------------- | ------- | ------------------------------------------------------------------------------- |
| 配信画面              | -       | libmpv が描画する動画領域。CSS では透明 / 黒のプレースホルダ                    |
| レス一覧              | -       | 現在のスレッドのレスをスクロール表示。仮想スクロール対応                        |
| スクロールバー        | -       | **OS 標準**を使用。CSS (`::-webkit-scrollbar`) で色・幅だけテーマに合わせる     |
| スレッドタイトル帯    | オレンジ | 現在見ているスレタイ + レス件数。クリックでスレ一覧表示？ (TBD)                 |
| 書き込みテキストボックス | 黒    | プレースホルダで「ここに書き込む」。Enter で改行、Ctrl/Cmd+Enter で送信         |
| ステータス帯          | 緑   | チャンネル名 / ビットレート / FPS。クリックでチャンネル詳細ダイアログ？ (TBD)   |

> スクロールバーに未読位置・アンカー参照位置などのマーカーを重ねたい要件は現状なし。
> 将来そういった需要が出たら独自描画に差し替える。

### 境界線のリサイズ

- 配信画面とレス一覧の境界 (垂直スプリッタ) は **ドラッグでリサイズ可能**
- 比率は設定に保存し、起動時に復元
- 最小幅: 配信画面 320px、レス一覧 200px (それ以下は片方が隠れる)
- ダブルクリックでスナップ位置に戻る (例: 75% / 25%)

### 各帯のリサイズ

- 書き込みテキストボックスのみ自動で高さが伸びる (改行行数に応じて)
- スレッドタイトル帯 / ステータス帯は固定高 (≈ 24px)

## インタラクション

### 配信画面

| 操作              | 動作                                                           |
| ----------------- | -------------------------------------------------------------- |
| ダブルクリック    | ウィンドウ全体をフルスクリーン化 (再度ダブルクリックで解除)    |
| 右クリック        | コンテキストメニューを表示 (下記参照)                          |
| ホイール          | 音量調整 (上で +、下で −)                                      |
| ドラッグ          | ウィンドウ移動 (ボーダーレス時)                                |
| キーボードの space | 再生/一時停止 (mpv 標準)                                       |

### コンテキストメニュー (右クリック)

PCRPlayer 同様、主要機能をまとめる。グルーピング案:

```
┌─ 再生 ──────────────────────────┐
│ ▶ 再生 / ⏸ 一時停止 / ■ 停止    │
│ 音量 ▶                          │
│ サイズ ▶ (50%/75%/100%/...)     │
│ アスペクト比 ▶                  │
├─ チャンネル ────────────────────┤
│ チャンネル情報...               │
│ 再接続 (Bump)                   │
│ 切断 (Stop)                     │
│ コンタクト URL を開く           │
│ チャンネル URL をコピー         │
├─ ウィンドウ ────────────────────┤
│ ☑ 最前面表示                    │
│ ☐ タイトルバーを隠す            │
│ ☐ BBS ペインを隠す              │
│ □ 全画面                        │
├─ ツール ────────────────────────┤
│ スナップショット                │
│ 設定...                         │
│ バージョン情報...               │
└─────────────────────────────────┘
```

「再接続」「切断」は PeerCast 本体への JSON-RPC コマンド (`bumpChannel` / `stopChannel`) を発火。

### レス一覧

| 操作                           | 動作                                                    |
| ------------------------------ | ------------------------------------------------------- |
| スクロール (ホイール/ドラッグ) | 一覧をスクロール                                        |
| アンカー (>>N) クリック        | 該当レスをポップアップでプレビュー (Hover で軽量表示)   |
| ID クリック                    | 同一 ID のレスを抽出ポップアップ                        |
| URL クリック                   | デフォルトブラウザで開く                                |
| 右クリック (レス)              | コピー、レス番号でアンカー挿入、抽出 等                 |
| 自動スクロール                 | 既定 ON。手動スクロール時は一時停止                     |
| 新着が画面外に届いた時         | スクロールバー脇に「N 件の新着」表示 (将来)             |

### スレッドタイトル帯

| 操作          | 動作                                                          |
| ------------- | ------------------------------------------------------------- |
| クリック      | **スレ一覧ウィンドウを表示** (下記参照)                       |
| 右クリック    | コピー / ブラウザで開く / 別スレに切替 等                     |

#### スレ一覧ウィンドウ

メインとは別の小ウィンドウ。

```
┌─────────────────── スレッド一覧 ──── [更新] [×] ┐
│ ▢ テストスレ part12         (487)  2026/05/30   │
│ ▢ 雑談スレ part58           (102)  2026/05/29   │
│ ▶ いまここ ★              (231)  2026/05/30   │  ← 現在表示中はハイライト
│ ▢ 質問スレ                  ( 48)  2026/05/28   │
│ ...                                              │
│                                                  │
└──────────────────────────────────────────────────┘
```

- 現在見ている板の `subject.txt` を取得して一覧表示
- 列: スレタイ / レス数 / 最終更新 (取得できる場合)
- **「更新」ボタン**でスレタイ一覧を再取得
- **スレッド行をクリック**するとメインウィンドウの BBS ペインがそのスレに切り替わる (ウィンドウは閉じても閉じなくてもよい、設定で選択)
- 現在表示中のスレは行をハイライト
- ウィンドウ位置・サイズは記憶

### 書き込みテキストボックス

| 操作              | 動作                                                          |
| ----------------- | ------------------------------------------------------------- |
| 入力              | 通常のテキスト入力                                            |
| Enter             | 改行 (テキストボックスが下に伸びる)                           |
| Ctrl/Cmd + Enter  | 送信 (確認ダイアログ → POST)                                  |
| Esc               | 内容クリア                                                    |
| Tab               | フォーカス移動                                                |
| 右クリック        | 標準テキスト操作 + 「名前/メール欄を開く」                    |

- 名前・メール欄は普段は非表示。必要時にだけ展開 (アイコンクリックで表示)
- 文字数カウンタを右下に小さく表示

### ステータス帯

| 表示項目      | 例                                          |
| ------------- | ------------------------------------------- |
| チャンネル名  | `RadioPSTPlayer`                            |
| ビットレート  | `120/256 kbps` (受信/上限)                  |
| FPS           | `(29.8/30 fps)` (現在/最大)                 |
| 接続状況      | アイコン or 色で表現 (緑=正常、橙=低速 等) |

| 操作         | 動作                                  |
| ------------ | ------------------------------------- |
| クリック     | チャンネル詳細ダイアログを表示        |
| 右クリック   | コピー (チャンネル名 / URL)           |

## 全画面モード

```
┌─────────────────────────────────────────────────┐
│                                                 │
│                                                 │
│                                                 │
│            配信画面 (動画)                      │
│                                                 │
│                                                 │
│                                                 │
│                                                 │
└─────────────────────────────────────────────────┘
```

- BBS ペイン / スレタイ帯 / 書き込み欄 / ステータス帯はすべて非表示
- マウスを下端に近づけると一時的にステータス帯がオーバーレイ表示 (mpv 風)
- Esc または ダブルクリックで解除

## 設定ダイアログ (別ウィンドウ案)

メインウィンドウとは別の小ウィンドウで開く。タブ構成:

| タブ          | 主な項目                                                            |
| ------------- | ------------------------------------------------------------------- |
| 一般          | 起動時設定、自動更新、テーマ (ダーク/ライト)                        |
| PeerCast      | ホスト/ポート、自動起動の有無、ユーザエージェント                   |
| BBS           | デフォルト名前/メール、自動更新間隔、HTML 表示モード切替           |
| プレイヤー    | 既定アスペクト比、音量初期値、スナップショット保存先                |
| ショートカット | キー割り当て一覧 + カスタマイズ                                    |
| ネットワーク  | プロキシ、タイムアウト                                              |

## ウィンドウ状態の永続化

終了時に保存し、起動時に復元する項目:

- ウィンドウ位置 / サイズ
- 配信画面と BBS ペインの分割比
- 最前面 ON/OFF
- ボーダーレス ON/OFF
- 最後に再生したチャンネル URL (任意、設定で OFF 可)

## モバイル / 小画面の検討

v1.0 ではデスクトップ前提。タブレット縦持ち時など狭幅では BBS ペインを下に回す案も将来検討。

## アクセシビリティ (最低限)

- キーボードでメインの全機能を操作可能
- フォーカスリングを CSS で明示
- 色だけでなくアイコン / テキストで状態を表現 (緑赤の色弱対策)

## 配信画面の動画スケーリング

配信動画はウィンドウの表示領域に合わせて単純に引き伸ばし・縮小する。元動画の解像度に固定はしない。

- libmpv の設定: `keepaspect=yes` (アスペクト比は維持してフィット)、`video-unscaled=no` (元解像度に固定しない)
- アスペクト比は別途「アスペクト比切替」メニューで自動/16:9/4:3 等を切り替え可能
- ウィンドウサイズ変更時は即座に追従
