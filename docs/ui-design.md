# UI デザイン

PSTPlayer のメインウィンドウのレイアウトとインタラクション仕様。

> **本書のスコープ**: 引数あり起動の **ビューア画面** (動画 + BBS
> ペイン) のレイアウトのみを扱う。引数なし起動の **ハブ画面**
> (PeCaRecorder 風テーブル) は [`usage/hub.md`](usage/hub.md) と
> [`design/pstplayer-hub-mockup.svg`](design/pstplayer-hub-mockup.svg) /
> [`design/pstplayer-hub-interactions.md`](design/pstplayer-hub-interactions.md)
> を参照。
>
> **画像**: `docs/images/main-layout.png` に元案のスクリーンショットを配置予定 (オーナーから提供された設計案)。
>
> **キーボードショートカット**: 本文中の `(T)` `(Z)` `(X)` 等は割り当て例。全一覧は [`shortcuts.md`](shortcuts.md) を参照。

## メインウィンドウ レイアウト

```
┌───────────────────────────────────────────┬───────────────┐
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │   レス一覧    │
│              配信画面 (動画)              │     表示      │
│                 (libmpv)                  │   (BBS ペイン)│ scrollbar
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │               │
│                                           │               │
├───────────────────────────────────────────┴───────────────┤
│ スレッドタイトル (件数)                                   │  ← オレンジ帯
├───────────────────────────────────────────────────────────┤
│ 書き込みテキストボックス                                  │  ← 黒帯 (可変高)
│ (Enter で改行 → 自動で下に広がる)                         │
├───────────────────────────────────────────────────────────┤
│ チャンネル名  受信bps/最大bps  (現在fps/最大fps)          │  ← 緑帯 (ステータス)
└───────────────────────────────────────────────────────────┘
```

### 各エリアの役割

| エリア                | 色 (案) | 内容                                                                            |
| --------------------- | ------- | ------------------------------------------------------------------------------- |
| 配信画面              | -       | libmpv が描画する動画領域。CSS では透明 / 黒のプレースホルダ                    |
| レス一覧              | -       | 現在のスレッドのレスをスクロール表示。仮想スクロール対応                        |
| スクロールバー        | -       | **OS 標準**を使用。CSS (`::-webkit-scrollbar`) で色・幅だけテーマに合わせる     |
| スレッドタイトル帯    | オレンジ | 現在見ているスレタイ + レス件数。クリックでスレ一覧表示？ (TBD)                 |
| 書き込みテキストボックス | 黒    | プレースホルダで「ここに書き込む」。Enter で改行、送信キーは Ctrl/Cmd+Enter (デフォルト) と Shift+Enter のいずれかを設定で選択 |
| ステータス帯          | 緑   | チャンネル名 / ビットレート / FPS。クリックでチャンネル詳細ダイアログ？ (TBD)   |

> スクロールバーに未読位置・アンカー参照位置などのマーカーを重ねたい要件は現状なし。
> 将来そういった需要が出たら独自描画に差し替える。

### 境界線のリサイズ

- 配信画面とレス一覧の境界 (垂直スプリッタ) は **ドラッグでリサイズ可能**
- 比率は設定に保存し、起動時に復元
- 最小幅: 配信画面 320px、レス一覧 200px (それ以下は片方が隠れる)
- ダブルクリックでスナップ位置に戻る (例: 75% / 25%)

### 各帯のリサイズ

- 書き込みテキストボックスのみ自動で高さが伸びる (改行行数に応じて)
- スレッドタイトル帯 / ステータス帯は固定高 (≈ 24px)

## インタラクション

### 配信画面

| 操作              | 動作                                                           |
| ----------------- | -------------------------------------------------------------- |
| ダブルクリック    | ウィンドウ全体をフルスクリーン化 (再度ダブルクリックで解除)    |
| 右クリック        | コンテキストメニューを表示 (下記参照)                          |
| ホイール          | 音量調整 (上で +、下で −)                                      |
| ドラッグ          | ウィンドウ移動 (ボーダーレス時)                                |
| キーボードの space | 再生/一時停止 (mpv 標準)                                       |

### コンテキストメニュー (右クリック)

PCRPlayer 同様、主要機能をまとめる。グルーピング案:

```
┌─ 再生 ──────────────────────────┐
│ ▶ 再生 / ⏸ 一時停止 / ■ 停止    │  ← ライブ用途のため通常使わない
│ 音量 ▶                          │     (リレー再構築失敗時の最終手段)
│ サイズ ▶ (50%/75%/100%/...)     │
│ アスペクト比 ▶                  │
├─ チャンネル ────────────────────┤
│ チャンネル情報...               │
│ 再接続 (Bump)                   │  ← 配信が止まったらまずこれ
│ 切断 (Stop)                     │
│ コンタクト URL を開く           │
│ チャンネル URL をコピー         │
├─ 表示 ▶ ────────────────────────┤  ← 各要素の表示 ON/OFF はここに集約
├─ ウィンドウ ────────────────────┤
│ ☑ 最前面表示          (T)       │
│ □ 全画面              (Enter)   │
│   最小化                        │
├─ ツール ────────────────────────┤
│ スナップショット                │
│ 設定...                         │
│ バージョン情報...               │
└─────────────────────────────────┘
```

- 「再接続」「切断」は PeerCast 本体への JSON-RPC コマンド (`bumpChannel` / `stopChannel`) を発火
- **再生/一時停止/停止の位置づけ**: PeerCast はリアルタイムストリーミングのため、通常視聴中にこれらを使う場面はほぼない。リレーが崩れて「再接続 (Bump)」をしてもうまく回復しないときに、いったん停止して状態をリセットする最終手段として用意する。OSC のようなオーバーレイ UI は設けず、右クリックメニューとホットキーからのみアクセスする。

### 「表示」サブメニュー

ウィンドウに何を表示するかは、すべてここの ON/OFF で切り替える (PCRPlayer 互換)。表示要素はすべて **動画の周辺に配置されるバー/帯** であり、動画自体に半透明で重畳されるものはない。

```
┌─ 表示 ──────────────────────────────────────────┐
│ ☑ 最前面表示                            (T)     │
│ ───────────────────────────────────────────── │
│ ☑ フレーム (ウィンドウ枠)               (Z)     │
│ ☑ タイトルバー                          (X)     │
│ ☑ ステータスバー                        (B)     │
│ ☑ BBS ペイン                            (C)     │
│   BBS ペイン位置 ▶ (上/下/左/右)                │
│ ☑ BBS ペインの書き込み欄表示                    │
│ ───────────────────────────────────────────── │
│ ☑ タイトルバーに画面サイズ表示                  │
│ ☐ タイトルバーにソースサイズ表示                │
│ ───────────────────────────────────────────── │
│ ☑ ステータスバーに FPS 表示                     │
│ ☐ ステータスバーに画面サイズ表示                │
│ ☑ ステータスバーの時間を可変表示                │
│ ☑ ステータスバーで再生情報を優先表示            │
│ ───────────────────────────────────────────── │
│ ☑ BBS ペインにスレ自動更新カウンター表示        │
└─────────────────────────────────────────────────┘
```

- 大分類は **「バー類の表示 ON/OFF」 → 「各バー内の表示要素 ON/OFF」** の二段構え
- すべての項目は **個別に永続化** (設定に保存され、起動時に復元)
- 主要なものはキーボードショートカット直接でも切替可 (T/Z/X/B/C は PCRPlayer 互換のキー割当)
- 「BBS ペイン位置」: PCRPlayer 同様 上/下/左/右 から選択 (デフォルトは右)
- BBS ペインを OFF にすると、書き込み欄表示などの子オプションも実質無効化
- 全画面モードはこの設定とは独立に動作 ([全画面モード](#全画面モード) 参照)

### レス一覧

| 操作                           | 動作                                                    |
| ------------------------------ | ------------------------------------------------------- |
| スクロール (ホイール/ドラッグ) | 一覧をスクロール                                        |
| アンカー (>>N) クリック        | 該当レスをポップアップでプレビュー (Hover で軽量表示)   |
| ID クリック                    | 同一 ID のレスを抽出ポップアップ                        |
| URL クリック                   | デフォルトブラウザで開く                                |
| 右クリック (レス)              | コピー、レス番号でアンカー挿入、抽出 等                 |
| 自動スクロール                 | 既定 ON。手動スクロール時は一時停止                     |
| 新着が画面外に届いた時         | スクロールバー脇に「N 件の新着」表示 (将来)             |

### スレッドタイトル帯

| 操作          | 動作                                                          |
| ------------- | ------------------------------------------------------------- |
| クリック      | **スレ一覧ウィンドウを表示** (下記参照)                       |
| 右クリック    | コピー / ブラウザで開く / 別スレに切替 等                     |

#### スレ一覧ウィンドウ

メインとは別の小ウィンドウ。

```
┌─────────────────── スレッド一覧 ──── [更新] [×] ┐
│ ▢ テストスレ part12         (487)  2026/05/30   │
│ ▢ 雑談スレ part58           (102)  2026/05/29   │
│ ▶ いまここ ★              (231)  2026/05/30   │  ← 現在表示中はハイライト
│ ▢ 質問スレ                  ( 48)  2026/05/28   │
│ ...                                              │
│                                                  │
└──────────────────────────────────────────────────┘
```

- 現在見ている板の `subject.txt` を取得して一覧表示
- 列: スレタイ / レス数 / 最終更新 (取得できる場合)
- **「更新」ボタン**でスレタイ一覧を再取得
- **スレッド行をクリック**するとメインウィンドウの BBS ペインがそのスレに切り替わる (ウィンドウは閉じても閉じなくてもよい、設定で選択)
- 現在表示中のスレは行をハイライト
- ウィンドウ位置・サイズは記憶

### 書き込みテキストボックス

```
通常時 (1 行分の細い帯):
┌───────────────────────────────────────────────┬───┐
│                                               │ ✎ │  ← 右端に書き込みアイコン
└───────────────────────────────────────────────┴───┘

入力中 (Enter で改行すると下に伸びる):
┌───────────────────────────────────────────────┬───┐
│ 1 行目                                        │ ✎ │
│ 2 行目                                        │   │
│ 3 行目                                        │   │
└───────────────────────────────────────────────┴───┘
```

- **通常時の高さは 1 行分** (細い帯)。配信画面エリアを圧迫しない
- Enter で改行されると、改行行数に応じて下方向 (テキストボックス自身) が伸び、配信画面エリアが上方向に縮む
- **伸縮アニメーションはなし** (即座に高さ変更)。動画レイアウトへの干渉を避けるため
- 右端に書き込みアイコン (PCRPlayer 同様)。アイコンクリックでも送信可能

| 操作              | 動作                                                          |
| ----------------- | ------------------------------------------------------------- |
| 入力              | 通常のテキスト入力                                            |
| Enter             | 改行 (テキストボックスが下に伸びる、アニメーションなし)       |
| Ctrl/Cmd + Enter  | 送信 (確認ダイアログ → POST)                                  |
| Esc               | 内容クリア                                                    |
| Tab               | フォーカス移動                                                |
| アイコンクリック  | 送信 (確認ダイアログ → POST)                                  |
| 右クリック        | 標準テキスト操作 + 「名前/メール欄を開く」                    |

- 名前・メール欄は普段は非表示。必要時にだけ展開 (アイコンクリックで表示)
- 文字数カウンタを右下に小さく表示

### ステータス帯

PCRPlayer 風のレイアウト。1 行の細い帯に集約。

```
┌────────────────────────────────────────────────────┬──────────┬─────┐
│ ニャム  2183/2128 kbps (59.99/60.00)               │ 05:21:01 │ 100 │
└────────────────────────────────────────────────────┴──────────┴─────┘
  左寄せ: チャンネル情報                              中央: 配信時間  右: 音量
```

| 表示項目      | 例                          | 説明                                            |
| ------------- | --------------------------- | ----------------------------------------------- |
| チャンネル名  | `ニャム`                    | 現在視聴中のチャンネル名                        |
| ビットレート  | `2183/2128 kbps`            | 受信ビットレート / 最大 (チャンネル設定値)      |
| FPS           | `(59.99/60.00)`             | 現在 FPS / 最大 FPS                             |
| 配信時間      | `05:21:01`                  | チャンネル稼働時間 (HH:MM:SS)                   |
| 音量          | `100`                       | 現在音量 (0-100)                                |
| 接続状況      | (任意) 色で表現             | 緑=正常、橙=低速、赤=停止中                     |

| 操作         | 動作                                  |
| ------------ | ------------------------------------- |
| クリック     | チャンネル詳細ダイアログを表示        |
| 右クリック   | コピー (チャンネル名 / URL)           |

## 全画面モード

```
通常 (改行なし):
┌─────────────────────────────────────────────────┐
│                                                 │
│                                                 │
│                                                 │
│            配信画面 (動画)                      │
│                                                 │
│                                                 │
│                                                 │
├─────────────────────────────────────────────────┤
│                                              ✎ │  ← 書き込み欄 (1 行分・常時表示)
├─────────────────────────────────────────────────┤
│ ニャム 2630/2128 kbps (59.98/60.00)             │  ← ステータス帯 (常時表示)
└─────────────────────────────────────────────────┘

書き込み欄が伸びた時 (上方向に広がる):
┌─────────────────────────────────────────────────┐
│                                                 │
│                                                 │
│            配信画面 (動画)                      │  ← 上方向に縮む
│                                                 │
├─────────────────────────────────────────────────┤
│ 1 行目                                       ✎ │  ← 改行ごとに上端が上に伸びる
│ 2 行目                                          │
│ 3 行目                                          │
├─────────────────────────────────────────────────┤
│ ニャム 2630/2128 kbps (59.98/60.00)             │
└─────────────────────────────────────────────────┘
```

- **BBS ペイン / スレタイ帯のみ非表示**
- **書き込み欄とステータス帯は常時表示** (PCRPlayer 同様、隠れない)
- 書き込み欄の挙動は通常時とは **逆方向 (上方向) に広がる**
  - 通常時: 下端が下へ伸びる → 配信画面が下方向に縮む
  - 全画面時: 上端が上へ伸びる → 配信画面が上方向に縮む
  - 書き込み欄の下端はステータス帯の上に固定
- 再生制御用の OSC 風オーバーレイは設けない (ライブ視聴のため不要)
- 右クリックメニューは全画面時も使える (Bump や 切断はそこから)
- Esc または ダブルクリックで解除

## 設定ダイアログ (別ウィンドウ案)

メインウィンドウとは別の小ウィンドウで開く。タブ構成:

| タブ          | 主な項目                                                            |
| ------------- | ------------------------------------------------------------------- |
| 一般          | 起動時設定、自動更新、テーマ (ダーク/ライト)                        |
| PeerCast      | ホスト/ポート、認証、接続テスト、履歴、自動起動。詳細は下記         |
| BBS           | デフォルト名前/メール、自動更新間隔、HTML 表示モード切替           |
| プレイヤー    | 既定アスペクト比、音量初期値、スナップショット (保存先/形式/通知)   |
| ショートカット | キー割り当て一覧 + カスタマイズ                                    |
| ネットワーク  | プロキシ、タイムアウト                                              |

### PeerCast タブ詳細

```
┌─ 設定 > PeerCast ──────────────────────────────────┐
│                                                    │
│  接続先                                            │
│  ┌──────────────────────────────────────────────┐  │
│  │ ホスト  [localhost            ▼]             │  │  ← 履歴ドロップダウン
│  │ ポート  [7144 ]                              │  │
│  └──────────────────────────────────────────────┘  │
│                                                    │
│  Basic 認証 (リモート時のみ)                       │
│  ┌──────────────────────────────────────────────┐  │
│  │ ユーザー [                  ]                │  │
│  │ パスワード [●●●●●●●●     ] [□ 表示]         │  │
│  └──────────────────────────────────────────────┘  │
│                                                    │
│  接続タイムアウト [5] 秒                           │
│                                                    │
│           [接続テスト]  → ✓ 応答 OK (v2.x.x)       │
│                                                    │
│  ───────────────────────────────────────────────  │
│                                                    │
│  ☐ 起動時に PeerCast 本体を自動起動                │
│    パス [C:\PeerCastStation\PeerCastStation.exe]   │
│                                                    │
│                              [キャンセル] [OK]     │
└────────────────────────────────────────────────────┘
```

- **履歴ドロップダウン**: 過去に接続した host:port を保存 (最新 10 件)、選択すると即座に欄に反映
- **接続テスト**: ボタン押下で `getVersionInfo` を呼び、結果 (成功なら API バージョン、失敗ならエラー内容) をボタン横に表示
- **パスワード**: 表面はマスク。「表示」チェックで一時的に平文表示
- **自動起動**: PCRPlayer の機能。当面は localhost 想定時のみ意味を持つ

### プレイヤータブ詳細 (スナップショット部分)

```
┌─ 設定 > プレイヤー > スナップショット ─────────────┐
│                                                    │
│  保存先                                            │
│  ┌──────────────────────────────────────────────┐  │
│  │ [(空 = exe 配下 snapshot/)            ] […] │  │  ← […] でフォルダ選択
│  │ 現在の解決先: D:\Apps\PSTPlayer\snapshot\    │  │  ← 解決後パスを表示
│  └──────────────────────────────────────────────┘  │
│                                                    │
│  形式  ⦿ PNG   ◯ JPEG (品質 [95])                  │
│                                                    │
│  ファイル名規則 (デフォルト)                       │
│   {YYYYMMDD_HHmmss}_{チャンネル名}.{ext}           │
│                                                    │
│  保存時の通知                                      │
│   ☑ ステータス帯に「保存しました」を表示           │
│   ☐ 保存後にファイルマネージャで開く               │
│   ☑ 連続スナップショット時はトースト抑制 (1 秒以内)│
│                                                    │
│                              [キャンセル] [OK]     │
└────────────────────────────────────────────────────┘
```

- 保存先欄が空の場合は `exe 配下 snapshot/` を意味する。「現在の解決先」に実際のパスを表示してわかりやすく
- exe 配下が書き込み不可なら、解決先表示は OS の Pictures フォルダになり、その旨が黄色で表示される

## ウィンドウ状態の永続化

終了時に保存し、起動時に復元する項目:

- ウィンドウ位置 / サイズ
- 配信画面と BBS ペインの分割比
- 最前面 ON/OFF
- ボーダーレス ON/OFF
- 最後に再生したチャンネル URL (任意、設定で OFF 可)

## モバイル / 小画面の検討

v1.0 ではデスクトップ前提。タブレット縦持ち時など狭幅では BBS ペインを下に回す案も将来検討。

## アクセシビリティ (最低限)

- キーボードでメインの全機能を操作可能
- フォーカスリングを CSS で明示
- 色だけでなくアイコン / テキストで状態を表現 (緑赤の色弱対策)

## 配信画面の動画スケーリング

配信動画はウィンドウの表示領域に合わせて単純に引き伸ばし・縮小する。元動画の解像度に固定はしない。

- libmpv の設定: `keepaspect=yes` (アスペクト比は維持してフィット)、`video-unscaled=no` (元解像度に固定しない)
- アスペクト比は別途「アスペクト比切替」メニューで自動/16:9/4:3 等を切り替え可能
- ウィンドウサイズ変更時は即座に追従
